TEST 01PDP buy-box rebuild P0 · Flagship

Why
PDP to Add-to-Cart is 1.20%. Industry benchmark is 4–7%. 9,059 PDP views / 28 days produced only 109 carts. The brand's real trust assets (4.9/2,847 reviews, GMA press, lifetime warranty, free engraving) are not in the buy box.
Target
PDP to ATC 1.20% → 1.80–2.40%. At $131 AOV: +25 to +50 incremental purchases / 28 days = +$3.3k to +$6.5k / month.

What to build (component spec)

Rebuild the right-column buy box on the product template. Apply to all PDPs. Top-5 PDPs by traffic first for the test:

  1. /products/brushback-grill-scraper
  2. /products/grand-slam-combo-set
  3. /products/triple-play-combo-set
  4. /products/mvp-combo-set
  5. /products/home-plate-cutting-board

Element order, top to bottom

  1. Product title (no change to text).
  2. Star rating row. 5 yellow stars + numeric rating (4.9) + review count link. Pulls live from Judge.me per-product widget. Click opens the reviews accordion below.
  3. Price. Existing styling. If on sale, strikethrough compare-at + savings tag.
  4. Variant selector. If multi-variant, keep existing radio/dropdown.
  5. Engraving option (NEW). Card-style checkbox with thick maroon border on hover. Label: "Add custom engraving (+$10)". Sub-label: "Text or logo. Ships in 1-2 business days." When checked, append _engraving line-item property to cart and add a $10 upsell SKU.
  6. Quantity stepper. Standard − / qty / + control.
  7. Add to Cart button (maroon, full-width). Text: "Add to cart · $XX.XX" where price updates dynamically when engraving is checked.
  8. Shop Pay express checkout button (already exists, keep below ATC).
  9. Brand-specific badges grid (2x2). Replace the current "Top Quality / Fast Ship / Support / SSL" badges with:
    • ⭐ Lifetime Warranty
    • ✎ Free Engraving
    • ⏱ Ships 1-2 Business Days
    • ⇪ Free Shipping over $100
    Each badge: maroon icon, dark text, light maroon background tint, full border.
  10. "As Seen On" press strip. Black background, yellow eyebrow "As Seen On", white logos: GMA · Live with Kelly · Fox News. Subtle box-shadow.
  11. For bundle PDPs only: Add a "What's included" labeled flat-lay image directly under the gallery. Show all components labeled with names.

Engraving option — implementation detail

Use Shopify line-item properties. When the checkbox is checked, the form posts properties[Custom engraving]=Yes (+$10) with the product. The +$10 charge can be handled two ways:

  • Recommended: Add a $10 add-on SKU (e.g. engraving-fee-10) to the cart in the same submit handler (one extra POST to /cart/add.js). Engraving instructions captured via a separate text field on the next step.
  • Alt: Use a Shopify app (Customily, Infinite Options) if a richer text/logo-upload UI is needed. App-based is faster to ship but adds 100-200ms TBT.

Tracking events to add (GTM datalayer)

// On PDP buy-box paint (variant only)
dataLayer.push({ event: 'pdp_variant_view', product_id: '{{ product.id }}' });

// On engraving checkbox toggle
dataLayer.push({ event: 'engraving_toggled', product_id: '{{ product.id }}', state: checked });

// On ATC click
dataLayer.push({ event: 'pdp_atc_click', product_id: '{{ product.id }}', engraving: checked });

Acceptance criteria

  • PDP loads identically on mobile and desktop for the variant.
  • Stars + review count visible above the fold on iPhone 13 (390 × 844).
  • Engraving checkbox adds $10 add-on SKU to cart correctly. Receipt shows engraving line item.
  • "As Seen On" strip does not push ATC button below the fold.
  • All 4 badge icons render correctly in Safari, Chrome, Firefox, Edge.
  • Total Blocking Time on PDP stays under +50ms vs control.

TEST 03Gift-Finder Quiz P1 · Flagship

Why
2,085 product variants and zero decision aid. The buyer is a gift-giver. Choice paralysis is structural. A quiz that returns "Recommended for him: Grand Slam Set" collapses the decision and creates an email retargeting asset.
Target
Quiz-completer purchase rate 3 to 6% (vs sitewide 0.80%). 500 monthly completions builds a list of warm leads for email retargeting.

What to build

Quiz card placement

  • Homepage hero (right side of evergreen hero, post Father's Day).
  • Gifts mega menu (primary entry).
  • End of paid social flow (Step 2 after the Father's Day LP, when re-routing post-season).
  • Persistent floating button bottom-right of every page ("Find the right kit") that opens the quiz overlay.

Six questions

  1. Who are you shopping for? (Dad / Grandpa / Brother or partner / Myself / Other)
  2. Favorite team? (MLB picker with grid + MiLB + College + Skip)
  3. How often does he grill? (Weekend warrior / Tailgater / Pro)
  4. Engrave text or logo? (Text only / Add a logo / No engraving)
  5. Budget tier? (Under $50 / $50–100 / $100–200 / $200+)
  6. Gift now or later? (Now / Within 2 weeks / Planning ahead)

Result logic

Map answers to one of three bundle recommendations:

  • Triple Play Set ($63): under $50–100 budget, weekend warrior.
  • Grand Slam Set ($117, default): $50–200 budget, any user (the most-recommended).
  • MVP Set ($177): $200+ budget, tailgater/pro.

Apply the selected team's licensing/SKU variant automatically. Pre-fill engraving text field with "Dad" or "[Their Name]" placeholder if Q1=Dad/Grandpa/Brother.

Pre-result email capture

Between Q6 and the result screen, show: "Where should we send your match? (we won't spam)" with an email field. Skippable. Captured emails go into Klaviyo with a quiz_completed tag and the recommended bundle as a custom property.

Result page

"Based on your answers, the Grand Slam Set is the right kit for him." Show the bundle preview with image, description ("5 tools. Bat-handle grips. Lifetime warranty. Free engraving with his name."), price + savings. Dual CTAs: "Add to cart" (primary maroon) and "See 2 more matches" (secondary outline) that opens a side panel with the runner-up bundles.

7Sticky mobile ATC bar A/B test P2

What. A persistent bottom bar on mobile PDPs that shows product thumbnail + variant + price + "Add to cart" button. Slides up after the user scrolls past the main buy box.

Why. Mobile already converts 14× better than desktop at PDP-to-ATC (8.13% vs 0.58%), but mobile scroll depth is only 42%. Half of mobile users lose visibility of the ATC button after scrolling past it.

Spec.

  • Appears at viewport bottom when buy box is scrolled out of view (use IntersectionObserver on the original ATC button).
  • Height: 64px on mobile, hidden on desktop.
  • Slide-up animation: 300ms ease-out.
  • Contents: 48px square product image | product title (truncated to 1 line) | variant (truncated) + price | Add to cart button (maroon, 44px tall).
  • Click ATC scrolls back to buy box AND triggers the add-to-cart action.

Files: snippets/sticky-atc.liquid (new), assets/sticky-atc.js, assets/sticky-atc.css.

Measurement: Mobile PDP-to-ATC rate. Target +10 to +20%.

8Drawer cart + OCU upsell flows (pre + post-purchase) A/B test P1

Why
Site uses the default cart page (not a drawer). ATC-to-Checkout is 50% (half abandon). At $131 AOV, even a 10% AOV lift is +$1.3k/month. Strong AOV lever.
Target
AOV +10 to +20%, ATC-to-Checkout drop -20 to -30%.

Two changes ship together

Part A: Drawer cart (replaces /cart page)

  • Open from header cart icon as a right-side slide-out drawer (350px wide on desktop, full-width on mobile).
  • Show cart items, quantity controls, line items (including engraving add-ons), subtotal.
  • Free shipping progress bar at top ("You're $XX away from free shipping").
  • Express checkout buttons: Shop Pay, Apple Pay, Google Pay (above standard Checkout button).
  • Trust strip in the drawer footer (Lifetime Warranty · Ships 1–2 Days).
  • The standalone /cart page remains accessible (some users prefer it) but the drawer is the primary cart experience.

Part B: One Click Upsell (OCU) flows

  1. Pre-purchase upsell (inside the drawer cart, after add-to-cart): "Customers also bought" or "Complete the set". Example: if cart has the Brushback Scraper, suggest the matching Slider Spatula at a 10% discount. One-tap add.
  2. Post-purchase upsell (on the thank-you page): a richer upsell with a 20% discount and 30-second timer. Example: "Add the Home Plate Cutting Board for $39 (regular $49). Same delivery." One-click add, no re-entering payment.

App recommendation: Zipify OneClickUpsell (OCU) for the post-purchase flow (industry standard, integrates with Shopify Checkout). For the pre-purchase drawer upsell, build native or use In Cart Upsell & Cross Sell.

9Sitewide free-shipping progress bar Ship Direct

What. A persistent progress bar in the header (or top of cart drawer) showing "You're $XX away from free shipping". Updates live as cart total changes.

Why. Free shipping is $100 on homepage but $150 on PDPs (inconsistent). Standardizing the threshold and surfacing progress motivates upsell and removes mixed messaging.

Spec.

  • Header announcement bar replaces current static "Orders over $100 eligible for free shipping" with dynamic: "$X away from free shipping. Add a tool →" when cart > 0.
  • When cart total ≥ $100: "Free shipping unlocked ✓".
  • Same bar appears at top of cart drawer (Part of Test 08).
  • Update Shopify settings to use $100 as the single threshold sitewide. Remove the $150 mention from PDPs.

Files. sections/announcement-bar.liquid, assets/free-ship-bar.js (reads theme.Shopify.cart.subtotal, recalculates remaining).

Measurement. AOV. Track items-per-cart pre and post.

10Fix Oakland Athletics PDP + audit team templates Ship Direct

What. Investigate why /products/oakland-athletics-team-jersey-cutting-board-... has 51 sessions / 28d and a 100% bounce rate. Likely a broken image, missing variant, template error, or 404. Audit all team-specific PDPs (30+ MLB teams) for the same pattern.

Why. Every broken team PDP burns paid traffic invisibly. If the bug repeats across teams, the impact compounds.

Steps.

  1. Open the Oakland PDP in Chrome DevTools. Check console for JS errors, check Network tab for failed asset loads, check the rendered HTML for missing variant options or empty Liquid blocks.
  2. Compare against a working team PDP (e.g. Yankees). Find the diff.
  3. Run a Shopify GraphQL query against products tagged with team metafields to flag any product with: missing images, no available variants, empty product.description, or 404 redirect handles.
  4. Fix the root cause (likely in templates/product.team-board.json or a missing metafield value).
  5. Re-test on Oakland. Confirm session bounce drops in GA4 within 7 days.

11Notify-me capture on sold-out variants Ship Direct

What. When a variant is sold out, replace the disabled "Out of stock" text with an email field: "Notify me when this is back in stock". Submit captures email + product variant ID into Klaviyo.

Why. Personalized SKUs and team-specific products go out of stock regularly. Today the visitor sees "Unavailable" and leaves. Notify-me captures intent.

Spec.

  • Replace the disabled variant button with a single email input + "Notify me" button.
  • POST to Klaviyo via the /api/identify endpoint with custom property back_in_stock_variant_id.
  • Klaviyo flow: when the variant's inventory_quantity goes from 0 to >0, send an email to all profiles with that variant in their property list.

App alternative. Back in Stock or Klaviyo's native Back-in-Stock flow if available.

Files. snippets/notify-me.liquid (new), assets/notify-me.js.

Tracking and data hygiene (run alongside)

Not tied to a specific test, but ship early in Week 1 because every other metric depends on clean data:

  1. Audit Web Pixels Manager + GTM coverage. Pixels (Meta, Clarity) are installed via Shopify WPM, which bypasses GTM debug. Misfires are invisible. A 1-hour audit verifies Meta Pixel events fire on every standard event (ViewContent / AddToCart / InitiateCheckout / Purchase) and that Meta CAPI is configured server-side. Also confirm Google Ads enhanced conversions are firing (look for enhanced_conversion_user_data in GTM preview).
  2. Add GA4 IP filter for SG / IN / VN / HK datacenter ranges. 26% of traffic is APAC bot. Distorts funnel, bounce, and Google Ads optimization signal. Filter via GA4 Admin → Data Settings → Data Filters. No revenue impact directly, but unlocks every downstream decision.
  3. Standardize tracking event naming. Apply the YM / ym_ prefix convention used elsewhere (GTM tags, GA4 events, Google Ads conversions) for any new events added by these tests.
